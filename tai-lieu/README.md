# Tài liệu gốc (thầy cung cấp)

Thầy bỏ tài liệu vào đúng thư mục lớp. Claude chỉ soạn nội dung web **dựa trên tài liệu ở đây**, theo đúng chương trình GDPT 2018 và bộ sách thầy dùng.

| Thư mục | Dùng cho phần web | Ghi chú |
|---|---|---|
| `lop9/` | Toán vào 10 (`data/vao-10/`) | Chương trình Toán 9, cấu trúc đề tuyển sinh, đề tham khảo, đề các năm |
| `lop10/` | Toán 10 (`data/lop10/`) | |
| `lop11/` | Toán 11 (`data/lop11/`) | |
| `lop12/` | Toán 12 + ôn thi tốt nghiệp THPT (`data/lop12/`) | |

## Nên để gì
- Mục lục SGK, nội dung bài / chương (PDF, ảnh, Word).
- Yêu cầu cần đạt, ma trận, đặc tả, cấu trúc đề của Sở / Bộ.
- Đề kiểm tra, đề thi, đề tham khảo kèm đáp án.
- Hướng dẫn chấm, quy định thống nhất (kiến thức được dùng / không được dùng).
- Ghi chú riêng của thầy (tệp `.md` hoặc `.txt`).

## Đặt tên tệp (gợi ý)
`<Chương hoặc chủ đề> - <loại tài liệu>.<đuôi>`, ví dụ:
- `Chuong 6 - Ham so y=ax2 - SGK.pdf`
- `De tham khao TS10 2026-2027 - TPHCM.pdf`
- `Cau truc de TS10 2026-2027 - slide.jpg`

Có thể tạo thêm thư mục con theo chương (`lop10/chuong-1/`…).

## Lưu ý
Các tệp tài liệu trong thư mục này **không đưa lên GitHub** (đã khai báo trong `.gitignore`) để tránh công khai SGK và đề có bản quyền. Chỉ các tệp `README.md` được lưu trên GitHub.
